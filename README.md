# sistem-panen-zollaa
# Sistem Pencatatan Hasil Panen Digital

**Deskripsi Singkat**
Proyek ini merupakan program Python sederhana yang dirancang untuk menghitung total pendapatan dari hasil panen komoditas agroindustri berdasarkan input berat (dalam kg) dan harga jual.

**Cara Menjalankan Program**
1. Pastikan bahasa pemrograman Python sudah terinstal di perangkat Anda.
2. Buka terminal (Command Prompt / Git Bash / Terminal VS Code).
3. Pastikan Anda berada di direktori (folder) yang sama dengan berkas program.
4. Ketikkan perintah berikut lalu tekan Enter:
   `python panen.py`
5. Masukkan data jumlah panen sesuai dengan instruksi yang muncul di layar.
